# VISTA-Beam
Official repository for **Vision-Only Joint Trajectory and Beam Prediction Over Long Horizons in mmWave V2I Systems**.

Guodong Sun, Anning Pang, Zhongji Yan, and Anhong Dang  
Peking University

## Overview
VISTA-Beam jointly predicts target UE trajectories and beam sequences from historical RGB images in millimeter-wave vehicle-to-infrastructure systems. It aggregates extrapolated point trajectories into a target UE trajectory and maps the predicted positions to beam selection probabilities.

All experiments are conducted on **Scenario 9** of the [DeepSense 6G](https://www.deepsense6g.net/) real-world dataset.
